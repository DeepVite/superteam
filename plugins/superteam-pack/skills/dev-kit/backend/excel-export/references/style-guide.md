# SaaS 导出表格统一样式规范（轮次 2、阶段 3 使用）

这份规范的目标：公司里**所有**导出功能产出的表格，打开后观感一致。轮次 2 生成 Excel 成品时逐项应用；阶段 3 开发时把每一项落到代码的样式工具类里。若用户提供了样式基准文件（`assets/`）或公司模板/截图，以用户提供的为准，本规范兜底。

## 一、整体结构

表格从上到下分三层：

1. **标题区**（可选，对外交付的报表建议有）：第 1 行合并单元格放大标题（如"2026年6月订单明细表"），14pt 加粗居中；第 2 行小字注明导出时间、导出范围（如"导出时间：2026-07-24 10:30　数据范围：2026-06-01 ~ 2026-06-30"），9pt 灰色。
2. **表头区**：1-N 行（多级表头时多行）。
3. **数据区**：数据行 + 可选合计行。

## 二、字体

| 位置 | 字体 | 字号 | 字重 | 颜色 |
|---|---|---|---|---|
| 大标题 | 微软雅黑 | 14pt | 加粗 | #1F1F1F |
| 表头 | 微软雅黑 | 10pt | 加粗 | #FFFFFF（深色底）或 #1F1F1F（浅色底）|
| 数据行 | 微软雅黑 | 10pt | 常规 | #1F1F1F |
| 合计行 | 微软雅黑 | 10pt | 加粗 | #1F1F1F |
| 备注/导出信息 | 微软雅黑 | 9pt | 常规 | #8C8C8C |

不要用 Excel 默认的等线/宋体 11pt——那是"没人管过样式"的标志。中文字体统一微软雅黑；纯数字列可以不管字体，跟着单元格走。

## 三、表头

- 背景色：浅灰 `#F2F2F2`（安全百搭）或品牌主色的浅色调；深色背景必须配白字。
- 对齐：**水平垂直都居中**。
- 边框：四边细边框，`#D9D9D9`。
- 行高：20-24pt，别用默认行高（太挤）。
- 多级表头：父级表头合并单元格居中，子级表头同样式；层级之间用背景色深浅区分（父级稍深）。

## 四、数据行

- **对齐规则（最重要的一条）**：文本左对齐、**数字右对齐**、日期/枚举/状态居中。数字右对齐后小数点自然对齐，扫一眼就能比大小；居中的数字列是样式不专业的首要信号。
- 边框：四边细边框 `#D9D9D9`。
- 行高：18-20pt。
- 斑马纹（可选）：数据超过 20 行建议加，偶数行底色 `#FAFAFA`，提升长表可读性。
- 长文本：列内容可能超长的（备注、地址），设置自动换行 + 固定行高，或者约定最大长度截断加"…"。**不要让单元格内容溢出把行高撑爆**。
- 空值：统一显示 `-` 或留空（全表只选一种），不要有的地方空白有的地方 "null"——`null` 字符串出现在导出文件里是事故。

## 五、数字格式（用单元格格式，不要在代码里拼字符串）

| 类型 | 格式串 | 说明 |
|---|---|---|
| 金额 | `#,##0.00` | 千分位 + 两位小数 |
| 整数数量 | `#,##0` | 千分位 |
| 百分比 | `0.00%` | 值存小数（0.156 → 显示 15.60%）|
| 日期 | `yyyy-mm-dd` | 统一短格式 |
| 日期时间 | `yyyy-mm-dd hh:mm` | 秒一般不需要 |
| 负数 | 随业务定 | 财务场景常用红色：`#,##0.00;[RED]-#,##0.00` |

为什么在代码里拼字符串是错的：拼成 `"1,234.56"` 后单元格变文本，用户拿到文件无法求和、无法排序、无法二次加工。数字必须存数值类型 + 显示格式。

## 六、列宽

- 不要用默认列宽。按内容类型设：ID/单号 20-25、名称 20-30、日期 12、日期时间 16、金额 14、状态/枚举 10、备注 30-40。
- 有 AutoSize 需求的：EasyExcel 可用 `LongestMatchColumnWidthStyleStrategy`；POI 的 `autoSizeColumn` 对中文不准（按字符宽度算），中文场景手动按"字符数 × 2.2"估算更稳。

## 七、冻结与打印

- 冻结首行（有标题区则冻结标题区+表头）：`freezePane`，长表滚动时表头不动。
- 对外交付的报表：设置打印区域、横向打印、页眉页脚（页码），产品经理打印出来不散架。

## 八、特殊行/单元格

- **合计行**：顶部边框加粗或双线上边框，底色 `#FFF7E6`（浅黄）或同表头灰，加粗。"合计"二字写在第一列。
- **异常/警示数据**：单元格字体红色 `#CF1322` 或浅红底色 `#FFF1F0`，全表语义统一（红=异常/负数，别又拿来标重点）。
- **状态列**：可以用字体颜色区分状态（成功绿 `#3F8600`、失败红、进行中蓝），但同一张表不超过 3 种颜色，多了就是调色盘。

## 九、颜色总原则

全表颜色 ≤ 4 种（表头底色、斑马纹、合计底色、警示色）。颜色的作用是**引导视线**，不是装饰。拿不准就只用"表头浅灰 + 细边框"，永远不会丑。

## 十、样式速查（EasyExcel / POI）

轮次 2 的成品用 Java 技术栈生成，规范的落法：

- **EasyExcel**：实现一个 `AbstractCellStyleStrategy`（或 `CellWriteHandler`），在 `afterCellDispose` 里按单元格位置套用规范——表头行给 HEADER 样式，数据行按列类型给对齐（文本左/数字右/日期居中），数字列设 `number_format`。全系统只写一份，所有导出复用。
- **POI**：建 `ExcelStyles` 工具类，工作簿创建时预建好全部 CellStyle（表头/文本/金额/日期/合计），渲染时只取不 new——**CellStyle 有数量上限（约 64000/工作簿）**，逐格创建会在大数据量时直接报错。
- 金额 `#,##0.00`、百分比 `0.00%`、日期 `yyyy-mm-dd` 等格式串都设在 CellStyle 的 DataFormat 上，值本身存数值/日期类型。

兜底速查（环境不便跑 Java、需要快速出样例时可用 Python openpyxl）：

```python
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side

HEADER_FONT = Font(name="微软雅黑", size=10, bold=True, color="1F1F1F")
HEADER_FILL = PatternFill("solid", fgColor="F2F2F2")
CENTER = Alignment(horizontal="center", vertical="center", wrap_text=True)
THIN = Side(style="thin", color="D9D9D9")
BORDER = Border(left=THIN, right=THIN, top=THIN, bottom=THIN)

cell.number_format = '#,##0.00'        # 金额
ws.freeze_panes = "A2"                  # 冻结首行
ws.column_dimensions["C"].width = 14
ws.row_dimensions[1].height = 24
ws.merge_cells("A1:F1")                 # 大标题/合计
```
