# Tooltip 文案规范

> 本文件是 `SKILL.md` 第二部分的展开。写文案前读它。
> 目标：前端能直接从功能逻辑推导出产品经理会认可的文案，产品经理不必再逐条写 tooltip 文案和排版。

## 1. 三步法

### 第一步：读功能

不要看元素名称，要看它背后的逻辑。把下面几个问题查清楚：

- 这个元素是什么？在哪个流程里？
- 点了会发生什么？会不会有不可逆后果？
- 数据从哪来？为什么是这个值？为什么可能是空的？
- 为什么它可能是灰的 / 不可点的？
- 有没有前置条件、权限、额度、依赖？

查法：读组件代码、读接口返回、读设计稿标注、读 PRD 相关段落。**没查清之前不要写文案。**

### 第二步：找疑问

把自己放在用户的位置：鼠标悬停在这里，心里在问什么？

| 场景 | 用户的疑问 |
|---|---|
| 一个陌生图标 | 这是什么？ |
| 一个灰掉的按钮 | 为什么不能点？怎么才能点？ |
| 一个危险操作 | 点了会删掉什么？能恢复吗？ |
| 一个数字 | 这个数怎么算的？跟上周比呢？ |
| 一个权限标签 | 我能做什么、不能做什么？ |
| 一片空白 | 为什么没有内容？我要做什么？ |
| 一个进度条 | 还剩多久？总共多少？ |

### 第三步：写答案

只回答那个疑问。不复述元素名称，不写元描述，不写「点击这里」。

## 2. 措辞规则

| 规则 | 好 | 坏 |
|---|---|---|
| 一句话说清「是什么 + 会怎样」 | 自动保存已开启。你的编辑内容每 30 秒保存一次。 | 此功能用于自动保存。 |
| 用用户的词 | 保存 | 提交持久化 |
| 动词开头、主动语态 | 复制链接到剪贴板 | 点击这里可以复制链接到剪贴板 |
| 数字带单位和上下文 | 4.2 MB · PDF · 修改于 2 天前 | 大小：4.2 |
| 危险操作说清后果和不可逆性 | 删除后不可恢复。该文档及其 12 条评论将被永久删除。 | 确定要删除吗？ |
| 受限操作说清原因和出路 | 你可以查看和评论，但不能编辑。如需编辑权限，请联系空间管理员。 | 权限不足 |
| 空状态说清原因和下一步 | 本周还没有新工单。创建第一个工单后，这里会显示趋势与负责人分布。 | 暂无数据 |
| 进度给总量和剩余时间 | 已同步 3,142 / 5,068 个文件，约 1 分 20 秒 | 62% |
| 新功能给版本和操作方法 | 按住 Alt 点击可添加多个光标，v2.5.0 起可用。 | 支持多光标编辑 |
| 不用感叹号、不写「请注意」 | 该操作会影响 8 位协作者 | 请注意！该操作会影响 8 位协作者！ |

## 3. 长度与排版

| 项 | 上限 |
|---|---|
| 标题 | ≤14 字 |
| 正文 | 每行 ≤ 约 20 字，最多 3 行 |
| 标签 | ≤3 个 |
| 按钮 | ≤2 个，主操作在右 |
| 列表项 | ≤5 条，超过改用页面 |

超限的处理顺序：**精简措辞 → 拆成标题+正文 → 改用可交互浮层 → 回退到页面内说明**。不要靠缩小字号或压缩行高硬塞。

排版约定：

- 标题给结论，正文给补充。
- 数据类：大数字 + 单位 + 环比 + 时间范围。
- 危险操作：说明在上，按钮在下，中间一条分隔线。
- 权限类：说明 + 能力标签 + 申请入口。
- 菜单类：动作在左，快捷键在右。

## 5. 常见错误

| 错误 | 问题 | 改法 |
|---|---|---|
| 复述元素名称 | 「保存按钮」——用户已经看到按钮了 | 说点了会发生什么 |
| 写「暂无数据」 | 用户不知道该怎么办 | 补一句「创建第一个工单后，这里会显示趋势」 |
| 写「操作失败」 | 用户不知道失败在哪、能不能重试 | 说清失败阶段 + 给重试入口 |
| 写「权限不足」 | 用户不知道怎么获得权限 | 说清能做什么 + 找谁申请 |
| 危险操作只写「确定吗」 | 用户不知道会删掉什么 | 说清范围和不可逆性 |
| 堆三行以上说明 | 悬停场景读不完 | 精简或改用页面内说明 |
| 用感叹号和「请注意」 | 制造焦虑、降低专业感 | 直接陈述后果 |
