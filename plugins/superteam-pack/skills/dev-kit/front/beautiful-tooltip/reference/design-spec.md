# Tooltip 设计规范（详细版）

> 本文件是 `SKILL.md` 第一部分的展开。动手写样式前读它。
> 宽度、对齐、箭头三条核心规则已与产品经理确认，不要自行更改默认值。

## 1. 设计令牌

### 1.1 浅色（默认）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--card` | `#ffffff` | 气泡底 |
| `--fg` | `#1b2333` | 主文字 |
| `--muted` | `#6b7690` | 次要文字、标签文字 |
| `--line` | `rgba(20,28,45,.1)` | 分隔线、按钮描边 |
| `--soft` | `#f2f5fb` | 标签底、统计块底 |
| `--shadow` | `0 10px 26px rgba(20,28,45,.13), 0 2px 6px rgba(20,28,45,.06)` | 投影 |

### 1.2 深色（跟随系统）

| 令牌 | 值 |
|---|---|
| `--card` | `#1c1c1f` |
| `--fg` | `#e8e8ea` |
| `--muted` | `#96969c` |
| `--line` | `rgba(255,255,255,.1)` |
| `--soft` | `rgba(255,255,255,.06)` |
| `--shadow` | `0 14px 34px rgba(0,0,0,.5), 0 2px 8px rgba(0,0,0,.35)` |

深色底一律用中性灰，**不要偏蓝**（`#181e2a` 这类蓝调深灰是被否掉的方案）。

### 1.3 主题色

主色走 `--accent` 令牌，预设蓝 / 紫 / 绿 / 橙（默认橙 `#FF8D00`）。会跟着变的：按钮、图标、进度条、头像、序号、链接、柱状图。**不会跟着变的**：成功绿、警示红、状态点——语义色不能被主题色带偏。

橙色 `#FF8D00` 上放白字对比度只有 2.3:1，产品经理明确要求按钮用白字，照做；如果要提升可读性，优先加字重而不是改主色。

### 1.4 语义色

| 用途 | 浅色 | 深色 |
|---|---|---|
| 成功 / 增长 | `#16a34a` | `#4ade80` |
| 危险 / 删除 | `#dc2626` | `#f87171`（文字/图标） |
| 危险按钮填充 | `#dc2626`（两种模式都用深红，避免深色下白字看不清） | 同左 |

## 2. 尺寸与间距

| 项 | 值 |
|---|---|
| 圆角 | 14px（菜单型可 8px） |
| 内边距 | 14px 16px |
| 箭头 | 8px 三角 |
| 箭头距圆角 | ≥14px |
| tooltip 与锚点间距 | 8px |
| 标题字号 / 字重 | 13px / 600 |
| 正文字号 | 12.5px，行高 1.6 |
| 按钮字号 | 11.5px |
| 最小宽度（自适应时） | 160px |
| 最大宽度 | 300px（固定档位 240 / 300 / 360） |

### 2.1 量化红线

| 项 | 上限 | 备注 |
|---|---|---|
| 短句 | ≤12 字 | 同时是自适应宽度的判据和居中判据 |
| 说明段 | ≤3 行 | 超过就精简，或改用可交互浮层 |
| 标签 | ≤3 个 | 超过换行或删 |
| 按钮 | ≤2 个 | 主操作在右 |
| 列表项 | ≤5 条 | 超过改用页面内说明 |

## 3. 宽度

### 3.1 判据

```
if (内容只有一行 && 最长一行 ≤12 字 && 无结构 && 无图标 && 无按钮)
    → 自适应：width: fit-content; min-width: 160px; max-width: 300px;
else
    → 固定：width: 300px（或 240 / 360）; max-width: 100%;
```

### 3.2 必须固定宽度的六种情况

1. 两行及以上（标题 + 正文）。
2. 结构化内容：标签行、进度条、柱状图、步骤列表、键帽、头像组。
3. 可交互内容：按钮、菜单项、可点链接——**点击区域不能随文案长短漂移**。
4. 含运行时变量：文件名、人名、计数、百分比——数据一变宽度就跳。
5. 同一列表/表格里重复出现的 tooltip——悬停切换时宽度要一致，不闪。
6. 数值/指标类——需要横向对齐比较。

### 3.3 唯一可以自适应的情况

单行、≤12 字、无结构、无图标、无按钮的纯文本。例：`复制链接到剪贴板`、`已保存`、`查看详情`。

### 3.4 常见错误

- 给带按钮的 tooltip 用自适应 → 按钮宽度抖动、点击区域漂移。
- 给含文件名/计数的 tooltip 用自适应 → 数据刷新时宽度跳。
- 自适应不加 `max-width` → 长文案变成一条横贯屏幕的带子。

## 4. 对齐

| 内容 | 对齐 |
|---|---|
| 单行、无结构、无图标 | 居中 |
| 两行及以上 | 居左 |
| 带图标 / 头像 | 居左 |
| 列表 / 步骤 / 键帽 / 标签行 | 居左 |
| 含按钮 / 操作 | 居左 |
| 数值 / 数据 | 居左或右对齐，不居中 |

判据：一「句」→ 居中；一「段」或一「列」→ 居左。带图标或按钮 → 一律居左。

## 5. 箭头位置

### 5.1 十二种位置与类名

| 边 | 起始 | 居中 | 末尾 |
|---|---|---|---|
| 下边（tooltip 在锚点上方） | `.a-bottom-start` | `.a-bottom-center` | `.a-bottom-end` |
| 上边（tooltip 在锚点下方） | `.a-top-start` | `.a-top-center` | `.a-top-end` |
| 左边（tooltip 在锚点右侧） | `.a-left-start` | `.a-left-center` | `.a-left-end` |
| 右边（tooltip 在锚点左侧） | `.a-right-start` | `.a-right-center` | `.a-right-end` |

「起始 / 末尾」在下边和上边指左右两端，在左边和右边指上下两端。

### 5.2 默认与自动行为

**命名语义**：`.a-top-*` 指箭头在 tooltip 的**上边**（箭头朝上 → tooltip 在锚点下方，等价于 `placement=bottom`）；`.a-bottom-*` 指箭头在 tooltip 的**下边**（箭头朝下 → tooltip 在锚点上方，等价于 `placement=top`）。先记住这条，否则默认位置会搞反。

1. **默认：tooltip 在锚点上方，箭头下边居中（`.a-bottom-center`）**。绝大多数场景。
2. **锚点上方空间不足 → 翻转到锚点下方，箭头上边居中（`.a-top-center`）**。
3. **上下都不足 → 改左右侧向**，侧向箭头默认垂直居中。
4. **水平方向超出视口 → 先夹紧 tooltip 位置，再把箭头从 center 改成 start 或 end**，保证箭头仍指向锚点。

这四种是定位算法的结果，不是给使用者的选项。调用方只声明偏好（如「优先下方」）。

### 5.3 必须偏移箭头的四种情况

1. 锚点靠近视口边缘：工具栏最右一个图标，tooltip 夹回视口后，箭头要落在 tooltip 右端。
2. 锚点比 tooltip 窄很多且贴边：把 tooltip 推向另一侧，箭头挪到靠近锚点的那一端。
3. 锚点是表格/列表里的某一列单元格：箭头对准该列的横向中心，而不是整行中心。
4. tooltip 会盖住用户正要看的相邻内容。

偏移量下限：距圆角 14px。

### 5.4 使用左右侧的三种情况

1. 锚点在垂直工具栏 / 侧边栏（左侧图标栏 → tooltip 在右侧，箭头在左边）。
2. 锚点位于视口顶部或底部，上下都放不下。
3. 上下方向的 tooltip 会盖住用户正在读的内容（图表坐标轴、表格行）。

## 6. 交互时序与动效

| 行为 | 规则 |
|---|---|
| 鼠标悬停出现 | 延迟 **400ms**（鼠标只是划过时不该闪出提示） |
| 鼠标移开消失 | 延迟 **150ms**（留出把鼠标移进 tooltip 的时间） |
| 键盘 focus | **立即**出现，不等 400ms |
| Esc | 关闭当前 tooltip |
| 触屏 | **点按切换**显示/隐藏（触屏没有 hover） |
| 默认位置 | tooltip 在锚点上方（`.a-bottom-center`），空间不足自动翻转 |
| 进入动画 | 150–200ms 淡入 + 位移 6–8px |
| 退出动画 | 150ms 淡出，无位移 |
| 减弱动效 | `prefers-reduced-motion: reduce` 时关闭过渡 |

不做弹跳、不做旋转、不做缩放放大。

## 7. 无障碍

- `role="tooltip"` + 锚点 `aria-describedby` 指向它。
- 键盘 Tab 聚焦锚点也能显示。
- 锚点若是纯图标按钮，本身要有 `aria-label`。
- tooltip 内容不要依赖颜色单独传意（红色同时配文字说明）。
- 可交互内容必须保证鼠标能移进去（无间隙或延迟消失），否则按钮点不到。

## 8. 反例清单

| 反例 | 为什么不行 |
|---|---|
| tooltip 里放必须点击的操作 | 鼠标一移开就消失，操作做不到 |
| 用 tooltip 承载长文 / 帮助文档 | 悬停场景读不完，也读不了 |
| 同一元素挂多个 tooltip | 用户不知道该信哪个 |
| 用 tooltip 代替表单校验错误 | 错误提示要常驻在字段旁 |
| 数值居中 | 数字无法对齐比较 |
| 自适应宽度装按钮 | 点击区域漂移 |
| 深色底偏蓝 | 与中性灰的界面底色不搭 |
| 语义红跟随主题色 | 危险提示失去警示性 |
