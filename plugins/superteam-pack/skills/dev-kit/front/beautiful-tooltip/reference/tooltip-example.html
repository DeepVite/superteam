Tooltip · 浅色卡片

02 号风格的 22 种生产级文案 · 显示模式默认浅色 · 主题色可切换

深浅色：显示模式默认浅色；切到「自动」跟随系统（Windows「设置 → 个性化 → 颜色」），切到「深色」手动锁定。tooltip 内部（文字、标签、键帽、进度条、警示色）一并切换，深色底为中性灰、不偏蓝。
主题色：主色抽成了 --accent 令牌，右侧面板点一下即换（蓝 / 紫 / 绿 / 橙色，蓝色在第一位）。按钮、图标、进度条、头像、序号、链接会一起变；语义色（成功绿、警示红、状态点）不参与换色。
宽度：默认固定 300px；只有极短的单行提示用 .tip--fit 自适应（160–300px）。箭头 12 种位置见第二节。
看什么：挑的是「内容模板」而不是这一种风格——你选中的模板我会用最终确定的外壳重新实现。

一、宽度策略 · 3 个案例对比

宽度分两大类：固定宽度（默认，绝大多数情况）与 自适应（.tip--fit：min-width 160px / max-width 300px）。
内容也分两大类：极短功能提示（单行、十来个字）→ 自适应；中等及以上文案 + 可交互提示（含按钮/菜单）→ 固定宽度。
